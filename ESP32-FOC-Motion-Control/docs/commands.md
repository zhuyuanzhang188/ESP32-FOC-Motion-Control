# 串口指令说明

串口波特率 **115200**；运动角度单位 **rad**，速度单位 **rad/s**，加速度单位 **rad/s²**，Jerk 单位 **rad/s³**。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `B<V>,<A>,<cruise_s>,<roundtrips>` | 梯形规划，自动往返 | `B6,8,1.5,3` |
| `C<V>,<A>,<J>,<distance>,<roundtrips>` | 七段式 S 曲线，自动往返；距离为相对位移 | `C2,4,60,8,3` |
| `N<absolute_target>` | 运动中修改绝对位置目标 | `N12` |
| `P` | 按规划受控制动，不是硬件急停 | `P` |
| `B0` / `C0` | 完成当前行程后取消剩余自动往返 | `C0` |
| `T<absolute_target>` | 普通绝对角度位置运动 | `T6.28` |
| `G` / `R` | 分别转到预设 3.14 rad / 0 rad | `G` |
| `H` | 空闲时保持当前测得位置 | `H` |
| `V<value>` / `A<value>` / `F<value>` | 调整运行参数（仍受内部约束） | `F1` |
| `S` | 简要运行状态 | `S` |
| `I` | 详细运行诊断 | `I` |
| `?` | 显示帮助 | `?` |
| `O` | 开关21列数值 CSV 输出 | `O` |
| `D` | 空闲时复位实验诊断统计 | `D` |

**尤其注意：** `N12` 是“到达绝对角度 12 rad”，并不是“再转12 rad”。`C` 的第四个参数是相对运动距离。发送命令前应核对当前位置、机械空间和轨迹制动距离。

## CSV 字段（I0～I20）

| 列 | 数据 | 列 | 数据 |
| --- | --- | --- | --- |
| I0 | uptime_ms | I1 | run_id |
| I2 | elapsed_ms | I3 | phase |
| I4 | 规划位置 | I5 | 实测位置 |
| I6 | 规划速度 | I7 | 实测速度 |
| I8 | 目标 Iq | I9 | 实测 Iq |
| I10 | Ud | I11 | Uq |
| I12 | Vmax | I13 | Amax |
| I14 | Kff | I15 | 启动时缓存 VIN |
| I16 | 已接受指令计数 | I17 | 已拒绝指令计数 |
| I18 | 最近指令 ASCII | I19 | 最近拒绝原因 |
| I20 | 发送丢弃计数 | | |

`SETTLED` 表示满足位置到位条件；`REPLACED` 表示运动被新指令接管；`NOT_SETTLED` 表示到位超时。被接管运动的 `final_err=NA`，不应当用其剩余到目标距离冒充最终到位误差。
