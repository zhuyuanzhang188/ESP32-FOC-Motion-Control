# 硬件配置与环境

下表来自当前可运行的固件配置，实际接线需要以所用 DengFOC-V4 板卡和电机为准。

| 硬件/参数 | 配置 |
| --- | --- |
| 控制器 | DengFOC-V4 / ESP32 |
| 电机 | 单轴 BLDC，7 极对 |
| 三相 PWM 驱动 | `BLDCDriver3PWM(32,33,25,12)` |
| AS5600 编码器 | `MagneticSensorI2C(AS5600_I2C)` |
| I²C | `TwoWire(0)`，SDA=GPIO19，SCL=GPIO18，400 kHz |
| 电流采样 | `InlineCurrentSense(0.01f, 50.0f, 39, 36)` |
| 母线电压 | 启动阶段使用 GPIO13 ADC 测量并缓存 |
| 供电 | 实验所用标称 12 V 电源；接线和功率能力必须自行核实 |
| 串口 | 115200 baud |
| FOC 库 | SimpleFOC 2.2.1 |

## 当前控制配置

- Q/D 轴电流 PI：P=5、I=1000；电流 LPF：Tf=0.002。
- 速度 PI：P=0.021、I=0.12、D=0。
- 位置 P：20；前馈系数：1.0。
- 速度上限设为 20 rad/s；代码中的软件电流指令限制 1.0 A。
- 软件角度边界为约 ±100 rad，是**规划检查参数，不是机械安全保证**。

> 安全提示：先空载或低速测试，确认编码器方向、极对数和电机限位，保证线缆不会缠绕。`P` 不能代替实体断电或急停。母线电压在实时循环中不反复进行 ADC 读取，以保持串口和控制时序稳定。
